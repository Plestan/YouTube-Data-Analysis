# 📊 YouTube Data Analysis with Python

This project focuses on collecting and analyzing YouTube trending video data using Python. It leverages the YouTube Data API and various data science libraries to uncover insights from trending content.

## 🔧 Features

- Fetch trending video data via the YouTube Data API
- Clean and preprocess data using `pandas`
- Visualize key metrics such as:
  - Video duration vs. view count
  - Average likes, comments, and views by video length
  - Publishing trends over time
- Identify patterns in engagement metrics

## 📦 Dependencies

- Python 3.8+
- pandas
- matplotlib
- seaborn
- google-api-python-client
